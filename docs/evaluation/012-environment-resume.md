## 恢复前置条件

首轮正常完成、独立功能验收通过、进程正常退出、数据库中的会话为 `closed`。
不满足时记录前置条件未满足，不补跑、不新建替代会话。

在同一 workspace、同一数据库的新进程中，通过现有 `--resume <完整会话ID>`
恢复；确认恢复后等待输入，且此前没有模型请求或历史工具自动重放，再发送追加需求。

## 评测者验收

- 首轮独立模拟 Windows、Linux、Darwin，检查 OS 和 Shell 与执行条件一致。
  同时检查 AGENTS.md 缺失、空白、非空及嵌套文件的行为。
- 恢复后检查新增 Python 信息来自运行进程，解释器路径为绝对路径；首轮行为仍成立。
- 两轮分别运行相关测试、完整 pytest、Ruff，并人工审核修改范围与报告是否属实。

  历史工具执行记录未改变；两次进程均正常关闭会话。
